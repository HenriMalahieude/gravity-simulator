# Heph's Gravity Simulator
Web Version:
https://henrimalahieude.github.io/gravity-simulator/

## Features:
* Semi-Realistic Simulation of:
    * Newtonian Gravity
    * Elastic Collisions
    * Blackhole Collapse
* Prediction System
    * See into the future
    * Scales down with more objects for performance
    * Only calculates when needed
* Gizmos:
    * Insert your own objects, make your solar system!
    * Time Scaling! Bored? Just push the time constant!
    * Inspection, where is this object going?
* Different World Starters:
    * Default Sun, Planet, Moon
    * Chaos World: Early System with only asteroids
    * Clear Area for the Meticulous Designer
